# 臺大選課志願序規劃器｜隱私權與資料使用說明

最後更新：2026-08-19

## 收集與儲存的資料

本擴充功能只保存使用者在臺大課程網安排的課程識別碼、志願序與儲存時間。資料寫入瀏覽器提供的 `chrome.storage.sync`，並由使用者登入的瀏覽器同步服務同步到同一帳號的裝置；同步暫時不可用時，會先保存在該裝置的 `chrome.storage.local`。

## 使用方式與分享

這些資料用來在 `https://course.ntu.edu.tw/priority/list/*` 還原與維持使用者的志願序、在 `https://course.ntu.edu.tw/priority/table` 依相同順序顯示同時段的課程，以及在臺大選課系統的「匯入預選課程」頁面產生差異預覽。只有使用者按下「確認並匯入」後，擴充功能才會將預覽中列出的流水號與志願序直接送到臺大選課系統；每一步都會驗證臺大系統回傳的結果。

本擴充功能沒有自有後端或分析服務，不會把資料交給開發者或廣告服務。除了使用者明確確認的臺大選課操作外，同步資料只會由使用者選擇的瀏覽器同步服務處理，不會用於廣告或建立使用者輪廓。

本擴充功能不讀取密碼、Cookie、帳號資訊或其他網站的瀏覽內容。

## 刪除資料

使用者可以在擴充功能彈出視窗按「清除所有排序資料」，刪除本擴充功能使用的同步與本機排序資料；也可以從瀏覽器的擴充功能資料管理介面刪除。

## 聯絡方式

上架時，請在 Chrome Web Store 的開發者資訊或支援頁面填入實際可用的聯絡方式。
